RADIENT_STATUS Diligent::RadientTesseraDrawableCache::PrepareMorphTargetData ( RadientFrameID RenderFrameID)

Selects active morph targets for every visible unique weights object and prepares the shader palettes for all its morph geometries together. Direct weight edits are detected through the weights object's version and do not require scene synchronization.

◆ PrepareSkinningData()

RADIENT_STATUS Diligent::RadientTesseraDrawableCache::PrepareSkinningData ( RadientFrameID RenderFrameID,
bool PackMatrixRowMajor = true )

Updates the shared joint-buffer shadow for every visible unique skin and pose pair whose pose version changed. Each pair is prepared once regardless of how many renderables or primitive slots reference it. RenderFrameID keeps repeated preparation during the same renderer frame from advancing motion history.
