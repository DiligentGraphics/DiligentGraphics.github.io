Detailed Description

CPU geometry with one shared index for all vertex attributes. Normals are always populated; optional texture coordinates and colors are either empty or have the same length as Positions. Missing values are zero UVs and white colors. Winding and texture V are not transformed; homogeneous positions are divided by W, with no further coordinate conversion.
