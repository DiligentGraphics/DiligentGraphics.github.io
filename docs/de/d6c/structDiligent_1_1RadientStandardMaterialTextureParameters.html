Detailed Description

Values of the seven parameters that define one standard-material texture semantic. SetStandardMaterialTextureParameters uses the definition-provided fallback texture when pTexture is null.

C++ default construction disables sampling (UVSelector = -1). Construction with a non-null texture selects UV set 0. C callers initialize all members explicitly; zero-initialization alone does not supply the C++ defaults.
