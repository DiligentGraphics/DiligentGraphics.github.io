Detailed Description

One selectable scene in an imported document.

Scenes refer to the document's shared node array and own their names and root-index arrays. A document may provide several scenes using the same nodes.

std::vector<Uint32> Diligent::RadientImport::ImportedScene::RootNodes

Owned array of zero-based indices in ImportedDocument::Nodes, in root instantiation order. These nodes are attached to the scene instance's root entity. An empty array describes an empty scene.
